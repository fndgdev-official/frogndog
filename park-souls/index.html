02 / FIRST VISIT

Set up once. Return here to play.

  1. 01

    Download the game.

    Use Download for Windows above. The ZIP contains the game and its small launcher.

  2. 02

    Extract everything.

    Right-click the ZIP and choose Extract All. Keep all extracted files together in a folder you plan to keep.

  3. 03

    Run ParkSouls.exe.

    Open ParkSouls.exe from that folder and choose Set up & open website. It registers the launch link in Windows and brings you back here.

  4. 04

    Click Play here.

    Choose Play Installed Game, then confirm your browser's request to open Park Souls. On future visits, start here.

Play didn't open the game.

This page cannot reliably check whether the game is installed. Make sure you extracted the ZIP and ran ParkSouls.exe once, then click Play again. Accept your browser's external-app prompt if it appears.

I moved the game folder.

Run ParkSouls.exe from its new location to update the launch link, then return to this page and click Play.

Can I play on a phone, Mac or tablet?

This preview is for Windows PCs with a keyboard and mouse. Mobile, tablet, macOS and Linux versions are not included.

The game reports missing prerequisites.

Run Support/UEPrereqSetup_x64.exe from the extracted game folder, complete the Unreal Engine prerequisites setup, then return here and try Play again.

Does this run inside my browser?

The browser opens the Windows game installed on your computer. Download and setup are required the first time; you do not need an FNDG account.
